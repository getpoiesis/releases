# φ — Releases

Signed builds of [φ](https://getpoiesis.com) for macOS, Windows and Linux, and
the auto-update feeds the app reads (`latest-mac.yml`, `latest.yml`,
`latest-linux.yml`).

Grab the current build from the
[Releases](https://github.com/getpoiesis/releases/releases) page, or from the
[download page](https://getpoiesis.com/download), which picks the right file for
you.

- **macOS** — `.dmg` (Apple silicon and Intel), Developer ID signed and notarized.
- **Windows** — `.exe` installer.
- **Linux** — `.AppImage` and `.deb`.

Source lives in a private repository; this one carries the builds only.
